## 📋 Sobre o Projeto

Este projeto implementa uma **Árvore Rubro-Negra**, uma estrutura de dados de árvore de busca binária auto-balanceável que garante complexidade **O(log n)** para operações de inserção, busca e remoção.

### 🎯 Características Implementadas
- ✅ **Inserção** com balanceamento automático
- ✅ **Rotação esquerda e direita**
- ✅ **Busca eficiente** O(log n)
- ✅ **Visualização** da árvore no terminal
- ✅ **Verificação** das 5 regras RN
- ✅ **Altura preta** calculada automaticamente
